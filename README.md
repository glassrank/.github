GlassRank is an independent project. We want to compare AI models in an honest and clear way.

We will test every model the same way. Everybody will see the tasks, the answers and the scores.

What we are building:

* GlassRank Bench, our own open test for AI models.
* The same tasks and settings for every model with a public API.
* An error bar next to every score.
* A tie when two models are too close.
* All tasks, answers and scores as open data.
* A free playground. You compare two answers without seeing the model names. These votes are a separate ranking.

This is early work. The first version of the test is not ready yet.
